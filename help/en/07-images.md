Under **Images**, describe what you want to see. FLUX.2 Klein makes the image on this Mac; earlier images are listed below it.

## Tips
- A description in **English** works best.
- **Improve with web**: the fast model first writes a better English description, and looks up what something looks like when needed. Every step is shown, with the model that does it.
- Choose the size at the top. On a Mac with little memory the app picks a smaller size.

## Where are they?
In `~/Pictures/MacAIMagic`, with the description in a file next to each image (not inside the image).

> A running chat model stops first when there is no room for both; a small chat model may stay.
