**System** checks at every start what MacAIMagic needs: the engine, the download tools, the models, disk space, the GPU limit and Apple's developer tools.

- What the app can fix itself, it fixes (such as macOS's quarantine block on the engine).
- For the rest there is a button.
- **Check again** runs the check once more.
- You also see which model suits this Mac best.
