icon: keyboard
keywords: shortcut keyboard keys
---
| Key | What |
|---|---|
| ⌘N | New conversation |
| ↩ or ⌘↩ | Send the message |
| ⌥↩ | New line in your message |
| ⌘V | Paste, also images and screenshots |
| ⌘, | Settings |
| ⌘? | This help |
| ↩ on an approval card | Allow |
| esc on an approval card | Deny |
