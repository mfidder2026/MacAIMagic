With **Web** on below the input field, the model searches the web itself (`web_search`) and reads pages (`fetch_url`). You see every step, and the sources below the answer.

## Search engine
- By default: **DuckDuckGo**, without an account.
- Or **Brave Search**, with your own API key: Settings → Chat → Web search.

## Privacy
Only the search query and the addresses of the pages go to the internet. The conversation itself stays on this Mac.

> A web page can contain text that tries to steer the model. That is why the model learns nothing for MACAIMAGIC.md after reading the web, and why a system change then gets an extra warning.
