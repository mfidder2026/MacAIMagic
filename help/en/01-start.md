MacAIMagic runs large AI models entirely on this Mac. Nothing goes to the cloud: your questions, files and answers stay here.

## In four steps
1. **System** checks what the app needs at every start. Anything shown in orange has a button that fixes it.
2. Choose a model under **Models**. Each card says whether it fits in this Mac's memory. The recommended model is the best one that fits whole.
3. Press **Download**. A download carries on after an interruption, and every file is checked.
4. Press **Start** and open a **New conversation** (⌘N).

> Close large programs before you start a big model: a compact model uses 110–120 GB of 128 GB.

## What can it do?
- **Chat**, with thinking, images and web search (see *Chatting* and *Web search*).
- **Work in a folder**: the model reads and writes files and runs commands (see *Working in a folder*).
- **Make images** under **Images**, and **Word documents** under **Documents**.
- **Compare models**, link several Macs in a **Cluster**, and use the model from other programs (see *Local API*).
- **Setting up this Mac**: the model looks at this Mac and sets it up for you, with skills per subject (see *System management*).

## Just ask the app
The model knows MacAIMagic. Just ask in the chat what you want, and it does it, after your approval on a card:
- "Which model fits this Mac best? Download it."
- "Turn thinking off and make the context 128K."
- "Make Ministral the fast model."
- "Make a skill for programming in C64 assembler."
- "Make an image of a lighthouse at sunset."

It reads the help itself and looks at how the app and this Mac stand. It does not change its own rights, API keys or the server address: you set those yourself. Deleting a model always asks. You can turn it off under Settings → System management → **The app**.

## Finding help
- Every page has **?** at the top right: it opens the help for that page.
- **⌘?** opens this help from anywhere.
- Type a word in the search field above, such as "password", "slow" or "Dock".
