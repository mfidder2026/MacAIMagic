**Systeem** controleert bij elke start wat MacAIMagic nodig heeft: de engine, de downloadtools, de modellen, de schijfruimte, de GPU-limiet en de ontwikkeltools van Apple.

- Wat de app zelf kan oplossen, lost hij op (zoals de quarantaineblokkade van macOS op de engine).
- Voor de rest staat er een knop bij.
- **Opnieuw controleren** voert de controle nog een keer uit.
- Je ziet ook welk model het best bij deze Mac past.
