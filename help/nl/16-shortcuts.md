| Toets | Wat |
|---|---|
| ⌘N | Nieuw gesprek |
| ↩ of ⌘↩ | Bericht versturen |
| ⌥↩ | Nieuwe regel in je bericht |
| ⌘V | Plakken, ook afbeeldingen en schermafbeeldingen |
| ⌘, | Instellingen |
| ⌘? | Deze hulp |
| ↩ op een goedkeuringskaart | Toestaan |
| esc op een goedkeuringskaart | Weigeren |
